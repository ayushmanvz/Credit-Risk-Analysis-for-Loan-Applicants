## Problem statement
Banks receive many loan applications every day, and before approving a loan they need to understand whether an applicant is likely to repay it. This project analyses income, loan amount, credit history, employment status, existing loans and repayment details to find the factors related to loan default, and builds an analytics-based approach to classify applicants by risk level (Low / Medium / High).

## Files
| File | Purpose |
|---|---|
| `index.html` | The website (dashboard, risk model, applicant checker). Works on GitHub Pages 24/7 |
| `loan_applicants.csv` | Dataset (1,500 applicants) - also loaded automatically by the website |
| `generate_dataset.py` | Python script that creates the CSV |
| `credit_risk_analysis.py` | Python analysis + Logistic Regression model, saves charts and `scored_applicants.csv` |
| `requirements.txt` | Python libraries needed |

> The dataset is synthetic (generated by code) for learning purposes, not real bank data. Mention this in your report/viva.

## Run the Python code
```
pip install -r requirements.txt
python generate_dataset.py
python credit_risk_analysis.py
```
Output: model accuracy/precision/recall/ROC-AUC in the terminal, `scored_applicants.csv`, and PNG charts in the `charts/` folder.

## Put the website online (GitHub Pages, free, 24/7)
1. Sign in at github.com -> click **New repository** -> name it `credit-risk-analysis` -> **Public** -> Create.
2. Click **uploading an existing file**, drag in ALL files from this folder (`index.html`, `loan_applicants.csv`, the `.py` files, `README.md`, `requirements.txt`) -> **Commit changes**.
3. Go to **Settings -> Pages**. Under *Build and deployment*, set Source = **Deploy from a branch**, Branch = **main**, Folder = **/ (root)** -> **Save**.
4. Wait 1-2 minutes. Your website link will be:

   `https://YOUR-GITHUB-USERNAME.github.io/credit-risk-analysis/`

   Open it in Chrome or any browser. It stays online 24/7 without any server.

## Risk levels
Low: predicted default probability < 30% | Medium: 30-60% | High: > 60%
